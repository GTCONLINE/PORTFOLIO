Withdrawal Plan (SWP)

Optional

One withdrawal plan, split however you like across portfolios — set the monthly amount to pull from each one below. Each can use its own expected return, keep a SIP going, or model its own market drawdown.

Total monthly withdrawal: Rs. 0

Advanced SWP — change the monthly withdrawal for a stretch of years, e.g. withdraw more from Year 6–10. Years are counted from the start of your portfolio (Year 0) — same as Special Withdrawals above — so whichever start point you have chosen for your SWP (from today / after SIP / after goal) is automatically factored in. Add a SWP, then set the monthly amount from each portfolio for it. The plan above counts as SWP 1; each one you add here shows up as SWP 2, SWP 3, and so on in the Statement of Account.

Goal & Required SIP

Optional

Every other portfolio is projected on its own entered numbers.

Tick which portfolios share the goal, then set each one's ratio yourself — they don't need to add up to 100; they're weighed proportionally against each other automatically. E.g. 30 and 30 splits the goal the same way as 50 and 50. Each portfolio's required SIP is shown against its current SIP. Unticked portfolios use their own entered SIP as-is.
